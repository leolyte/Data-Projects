## 🏥 Internship Project — Biobank Storage Monitoring

### Overview
During my internship, I developed an automated monitoring solution for biobank storage systems — replacing an error-prone manual process with a reliable, automated pipelines to monitor Freezer occupancy, cohort occupancy, procurements and promoters.

### Problem
Biobanks managing large volumes of biological samples need accurate, up-to-date visibility into storage occupancy across freezers and units. Previously, this was tracked manually — a slow process that made it difficult to plan capacity, detect inefficiencies, or produce reliable reports for audits.

### Solution
Built Python-based pipelines that automate the processing, and visualization of freezer storage occupancy data — giving the biobank a clear, repeatable view of how storage capacity is being used.

### Key Contributions
- Automated data ingestion and transformation from raw storage records
- Calculated occupancy metrics across freezer units to support capacity planning
- Generated structured visualizations and reports for operational decision-making and audit documentation
- Replaced ad hoc manual tracking with a reproducible, scalable workflow

## 🤖 Data Science Projects

### 1. Heart Failure Prediction
> Predicts the likelihood of death due to heart failure using clinical data and supervised machine learning.

Cardiovascular diseases claim an estimated **17.9 million lives per year** globally. This project builds and compares three classifiers — SVM, KNN, and Logistic Regression — to identify high-risk patients from clinical records.

| | |
|---|---|
| **Dataset** | PIMA Heart Failure Clinical Records (299 patients) |
| **Models** | SVM, K-Nearest Neighbors, Logistic Regression |
| **Best Accuracy** | ~84% (Logistic Regression) |
| **Stack** | Python, Pandas, NumPy, Matplotlib, Seaborn, scikit-learn |

### 2. Diabetes Prediction
> Predicts whether a patient is diabetic based on key medical indicators using a Support Vector Machine.

Built on the PIMA Indians Diabetes Dataset, this project covers the full ML pipeline — from EDA and feature standardization through to model serialization and a reusable prediction function.

| | |
|---|---|
| **Dataset** | PIMA Indians Diabetes Dataset (768 patients) |
| **Model** | Support Vector Machine (linear kernel) |
| **Accuracy** | 78.66% (train) / 77.27% (test) |
| **Stack** | Python, Pandas, NumPy, Matplotlib, Seaborn, scikit-learn |
