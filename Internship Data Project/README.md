# Biobank Freezer and Cohort Monitoring

A collection of Python scripts I developed for monitoring biobank storage occupancy and cohort sample utilization. The scripts automate data extraction and transformation from Excel inputs, generate visual reports on freezer capacity and sample metrics, and support operational decision-making in biobank management.

Built with Python (Pandas, Matplotlib, Plotly, glob, reportlab) and documented to institutional SOP standards.
